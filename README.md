# 🧮 Calculadora Simples em Python

Uma aplicação de linha de comando simples e funcional desenvolvida em Python para a realização de operações matemáticas básicas.

---

## 📝 Sobre o Projeto

O objetivo principal deste projeto foi praticar a lógica de programação em Python e consolidar o uso de **funções**, **estruturas condicionais** e **manipulação de entradas do usuário**. 

Foi desenvolvida uma interface interativa via terminal onde o usuário pode selecionar a operação desejada e fornecer dois números para obter o resultado imediatamente.

---

## 🚀 Funcionalidades

- **Soma:** Realiza a adição entre dois números.
- **Subtração:** Calcula a diferença entre dois números.
- **Multiplicação:** Efetua o produto de dois números.
- **Divisão com Validação:** Executa a divisão e conta com um controle de segurança que impede a divisão por zero, exibindo uma mensagem de aviso ao usuário.

---

## 🛠️ O que foi praticado durante a criação

Durante o desenvolvimento deste projeto, foram aplicados os seguintes conceitos da linguagem Python:

- **Modularização:** Uso de funções (`def`) para cada operação matemática, mantendo o código limpo, organizado e reaproveitável.
- **Entrada e Saída de Dados:** Manipulação de informações do terminal com `input()` e `print()`.
- **Coerção de Tipos (Casting):** Conversão de valores textuais capturados pelo `input()` para números decimais do tipo `float`.
- **Estruturas Condicionais:** Utilização de blocos `if`, `elif` e `else` para gerenciar a escolha da operação pelo usuário.
- **Validação de Regras de Negócio:** Tratamento lógico dentro da função `dividir` para lidar de forma graciosa com operações matematicamente inválidas.
